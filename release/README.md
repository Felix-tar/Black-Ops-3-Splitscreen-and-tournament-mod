# Fertige Mod zum Herunterladen

`bo3_splitscreen_qol-<version>.zip` enthaelt den spielfertigen Mod-Ordner.

Installation: ZIP in `...\steamapps\common\Call of Duty Black Ops III\mods\` entpacken, sodass
`mods\bo3_splitscreen_qol\zone\core_mod.ff` entsteht. Dann BO3 starten, MODS oeffnen und die Mod laden.

Gebaut wird das Paket mit `build-dev.ps1 -Release -Version <version>` (siehe HOW_IT_WORKS.md).
